### eDNA Classification Model
An AI pipeline to classify environmental DNA sequences using machine learning.  
**Tech:** Python, scikit-learn (or TensorFlow), pandas, numpy.  
**Features:**  
• Preprocesses real DNA rRNA datasets  
• Trains model to classify sequences  
• Evaluates accuracy & metrics  
**Usage:**  
```bash
pip install -r requirements.txt  
python train.py
